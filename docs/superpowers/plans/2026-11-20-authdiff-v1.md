# authdiff v1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PRD'deki authdiff aracını (OpenAPI + çoklu kimlik → BOLA/BFLA/NOAUTH/mass-assignment bulguları → JSON/SARIF/HTML/terminal), demo laboratuvarını (vuln-lab), GitHub Action'ı ve CI hattını v1.0 kapsamında üretmek.

**Architecture:** Tek yönlü boru hattı: `config` + `spec` → `identity` (profil + sahiplik havuzu) → `planner` (somut istek inşası) → `engine` (YAML kural şablonlarını çalıştıran motor + özel Go motorları) → `transport` (kapsam → güvenli mod → hız limiti → kayıt/maskeleme) → `compare` → `finding` → `report`. Güvenlik korumaları yalnızca `transport` katmanındadır; motorlar onu atlayamaz. Orkestrasyon `pkg/authdiff.Scan` içindedir; CLI ve e2e testi aynı girişi kullanır.

**Tech Stack:** Go 1.23+ (go.mod `go 1.23`), cobra, gopkg.in/yaml.v3, getkin/kin-openapi, golang.org/x/time/rate, golang.org/x/sync/errgroup, tidwall/gjson, expr-lang/expr, log/slog, charmbracelet/lipgloss, html/template+embed, stretchr/testify. vuln-lab: Python 3.12, FastAPI, SQLModel, PyJWT, Docker Compose.

**Spec:** `authdiff — Ürün Gereksinimleri Dokümanı (PRD).md` (depo kökü). Bölüm/özellik numaraları (F-xx, V-x) bu dosyaya atıftır.

## Global Constraints

- Modül yolu: `github.com/ardayesilcayir/authdiff`. `go.mod`: `go 1.23`.
- `cli` dışında hiçbir paket `cobra` import etmez. `report` yalnızca `finding`'i import eder. `engine` → `compare`, `finding`, `transport`, `planner`, `identity`, `rules`, `spec`, `config` kullanabilir.
- Varsayılanlar: rate `5` istek/sn, concurrency `4`, timeout `10s`, yanıt boyutu sınırı `5 MB` (5*1024*1024), similarityThreshold `0.85`, allowDestructive `false`, TLS doğrulama açık, retry en fazla `3` (exponential backoff).
- Yıkıcı method'lar: `DELETE`, `PUT`, `PATCH`. `--allow-destructive` olmadan transport bunları göndermez.
- Bulgu ID'si: `sha256(rule|method|path|victim|attacker)` hex'inin ilk 12 karakteri.
- Maskeleme: `Authorization`, `Cookie`, `Set-Cookie`, `X-API-Key` başlıkları ve config'deki tüm gizli değerler her çıktıda `****` + son 4 karakter (gizli değer 8 karakterden kısaysa yalnızca `****`).
- User-Agent: `authdiff/<version> (+https://github.com/ardayesilcayir/authdiff)`.
- Kapsam: `scope.allowHosts` boş veya `acknowledgeAuthorization != true` ise tarama başlamaz. Redirect dahil kapsam dışına tek istek gitmez.
- Çıkış kodları: `0` başarı, `1` `--fail-on` eşiği aşıldı, `2` hata/kullanım hatası.
- Yerleşik kural ID'leri: `AD-BOLA-001`, `AD-BOLA-002`, `AD-BFLA-001`, `AD-NOAUTH-001`, `AD-MASS-001`, `AD-METHOD-001`, ayrıca `AD-MATRIX-001` (F-12) ve `AD-LEAK-001` (F-19, P2).
- `internal/` için ≥ %80 satır kapsamı; `golangci-lint` uyarısı 0.
- Kod, yorumlar, README ve docs İngilizce; `README.tr.md` Türkçe çeviri (PRD 17.2 açık sorusu bu şekilde karara bağlandı).
- **Paralel çalışma kuralı:** Alt ajanlar yalnızca kendi task'ının dosyalarına dokunur, yalnızca kendi paketinin testlerini çalıştırır (`go test ./internal/<pkg>/...`), `go mod tidy`/`gofmt -w .` gibi depo geneli komut çalıştırmaz ve commit atmaz; commit'i koordinatör (ana oturum) atar. Bağımlılıklar Task 1'de `tools.go` ile önceden sabitlenir.

## Review Focus

1. **Host eşleşmesi normalizasyonu** — `allowHosts: ["localhost:8000"]` iken `http://LOCALHOST:8000` izinli; `allowHosts: ["example.com"]` iken `https://example.com` (port 443 varsayılan) izinli, `https://example.com.evil.io` yasak. (Task 4 testleri)
2. **Base URL'de path öneki** — `baseUrl: http://h/api` + `/orders/{orderId}` → `http://h/api/orders/101` (çift/eksik `/` yok). (Task 9 testi)
3. **Token'ın URL/redirect üzerinden sızması** — `apikey in: query` ile gönderilen anahtar ve `Location` başlığındaki token kanıtta maskeli. (Task 4 testi)
4. **Boş/JSON olmayan/204 yanıtlar** — `Similarity(empty, empty) == 1.0` ama BOLA kuralı sahip gövdesi boşsa bulgu üretmez; HTML hata sayfası çökertmez. (Task 5 ve Task 10 testleri)
5. **Eksik ortam değişkeni ve kötü niyetli yanıt** — `${env:ALICE_TOKEN}` tanımsızsa hata mesajı değişken adını içerir; 10.000 seviye iç içe JSON `Flatten`'ı çökertmez (derinlik sınırı 64), 5 MB üstü yanıt `Truncated=true`. (Task 2, 4, 5 testleri)

### Task 5: `internal/compare` — düzleştirme, dinamik alan, benzerlik, kanıt

**Files:** Create `internal/compare/structural.go`, `similarity.go`, `dynamic.go`, `evidence.go`, testler

**Interfaces:**
- Produces:
  - `func Flatten(body []byte) (map[string]string, bool)` — JSON değilse `(nil,false)`. Yollar `$.items[0].price` biçiminde; değerler kanonik JSON metni (`"abc"`, `12`, `true`, `null`); boş nesne/dizi yaprak olarak `{}`/`[]`; derinlik > 64 ise o dal tek yaprak olarak `"<depth-limit>"` (çökme yok). Sayılar `json.Number` ile korunur.
  - `func MatchPath(pattern, path string) bool` — `$.a.b` tam eşleşme, `$..x` herhangi bir derinlikte son anahtar `x` (ve altı), `[*]` herhangi bir indeks, `.*` herhangi bir anahtar.
  - `func DynamicPaths(a, b []byte) map[string]bool` — iki yanıtta değeri farklı veya yalnızca birinde olan yollar.
  - `type Options struct { IgnoreFields []string; Dynamic map[string]bool }`.
